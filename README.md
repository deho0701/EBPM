# 한의약 EBP DB 화면 시안

한의약 EBP DB를 정책시계열서비스 형태로 보여주는 화면 시안입니다.

## 기준 시안

**시안 1(`index.html`)이 기준입니다.** 이후 작업은 이 파일을 바탕으로 합니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 시안 1 (기준). 첫 화면, 시계열, 아카이브(정책현황·보도자료·국가통계) |
| `sian-3.html` | 시안 3. 정책도달단계 판별 화면 참고용 |
| `sian-4.html` | 시안 4. 정책도달단계 판별 화면 참고용 |
| `sian-5.html` | 시안 5. 정책도달단계 판별 화면 참고용 |

## 화면 보는 법

1. 이 페이지 오른쪽 위의 초록색 **Code** 버튼을 누르고 **Download ZIP**을 누릅니다.
2. 받은 압축 파일을 풉니다.
3. `index.html`을 더블클릭하면 브라우저에서 열립니다.

파일 하나에 화면과 자료가 모두 들어 있어서, 따로 설치할 것은 없습니다.

## 수정하는 법

수정은 자유롭게 하셔도 됩니다.

**깃허브 화면에서 바로 고치기**

1. 고칠 파일 이름을 누릅니다.
2. 오른쪽 위의 연필 모양 버튼을 누릅니다.
3. 내용을 고친 뒤 **Commit changes**를 누릅니다.

**내 컴퓨터에서 고치기**

1. 저장소를 내려받습니다.
   `git clone https://github.com/deho0701/EBPM.git`
2. 파일을 고칩니다.
3. 고친 내용을 올립니다.
   `git add .`
   `git commit -m "수정 내용"`
   `git push`
